# Partam 3D Showroom & Direct-Engine

**Interactive 360° E-Commerce Apparel Experience**  
Developed by **Partam Tekno** (Software Agency & Digital Solutions)  
Portfolio & Demonstration Engine by **Andi Asmul Fauzi, S.Kom.**

---

## 🌟 Tentang Proyek
Showcase teknologi **3D Interactive Showroom & Direct-Engine** yang mentransformasi katalog toko online konvensional (foto 2D statis) menjadi pengalaman pameran pakaian 3D interaktif 360° berbasis WebGL (Three.js) yang ringan, cepat, dan responsif di perangkat mobile maupun desktop.

Solusi ini dirancang untuk brand fashion/apparel lokal guna:
1. **Meningkatkan Dwell-Time hingga 3.4x**: Calon pembeli dapat menggeser rel pakaian, memilih jersey/baju, memutar 360°, dan memeriksa detail tekstur kain secara realistis.
2. **Penyelamat Margin Komisi (Direct-Engine)**: Menghubungkan pembeli langsung ke checkout WhatsApp atau formulir instan tanpa potongan komisi marketplace 18-21%.
3. **Bebas Sewa SaaS Bulanan**: Berjalan tanpa ketergantungan langganan bulanan mahal seperti Shopify.

---

## 🚀 Fitur Unggulan
* **3D Virtual Clothes Rail**: Rel gantungan pakaian 3D interaktif dengan material metalik dan pencahayaan studio sinematik.
* **360° Free Orbit / Rotation**: Fitur putar bebas dengan kontrol sentuh/mouse yang mulus (smooth damping).
* **Synthesized Audio Feedback**: Efek suara geser rel (*whoosh*), sentuhan gantungan (*clink*), dan klik tombol berbasis **Web Audio API** tanpa beban unduhan aset audio eksternal.
* **E-Commerce Direct Drawer**: Dilengkapi kartu perbandingan harga (*Hemat Rp 50.000 dibanding Marketplace*), pemilih ukuran, dan tombol pemesanan cepat 1-klik via WhatsApp.
* **Kalkulator Penghematan Komisi (B2B Lead Magnet)**: Simulator interaktif bagi pemilik brand untuk menghitung uang tunai yang diselamatkan setiap bulan.

---

## 🛠️ Tech Stack
* **3D Engine:** Three.js (r128), WebGL, GLTFLoader
* **3D Asset Pipeline:** Optimized low-drawcall GLB, PBR Standard Materials, Tangent Normal Mapping
* **Audio Engine:** Native Web Audio API Synthesizer
* **Typography & UI:** Inter / Plus Jakarta Sans, CSS Glassmorphism, Responsive CSS Grid
* **Deploy:** GitHub Pages (Static Edge CDN)
